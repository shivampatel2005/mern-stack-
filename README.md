# Student Registration Portal

A simple HTML student registration form built as a mini project for XYZ Institute.

## Files

- `index.html` — the full page: profile section, registration form, and three info tables
- `avatar.png` — image asset
- `businessman-character-avatar-isolated_24877-60111.avif` — image asset
- `istockphoto-1487465664-2048x2048.jpg` — profile photo shown at the top of the page
- `photo-1603415526960-f7e0328c63b1.avif` — image asset

## What's on the page

- **Student Profile** — a profile photo
- **Student Registration Form** — collects:
  - Full name, email, password, phone number, date of birth
  - Gender (radio buttons)
  - Skills: HTML, CSS, JavaScript, React (checkboxes)
  - Course selection (dropdown)
  - Preferred learning mode: Online / Offline (radio buttons)
  - Highest qualification (dropdown)
  - City (dropdown)
  - Address (textarea)
  - Register / Reset buttons
- **Course Details** — table of course, duration, and fees
- **Class Schedule** — table of day, subject, and time
- **Student Performance** — table of subject, marks, and grade

## Usage

Open `index.html` directly in a browser — no build step, server, or dependencies required. All image files must stay in the same folder as `index.html` since they're referenced by relative path.

## Notes

This is plain HTML with no CSS applied, so it renders using the browser's default styling.
